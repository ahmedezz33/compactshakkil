تطبيق CompactShakkil — مُشكِّل عربيّ
====================================
التشغيل:
  1) شغّل:  run_app.bat   (يُثبّت gradio عند اللزوم ثمّ يفتح الواجهة)
     أو يدويًّا:
        venv\Scripts\activate
        pip install gradio
        python app.py
  2) يفتح المتصفّح على http://127.0.0.1:7860
  3) الصِق النصّ (سطرٌ لكلّ جملة) واضغط «شكِّل».

كيف يعمل:
  - الآيات القرآنيّة تُستردّ من المصحف (دقّة 100%).
  - النصّ العامّ يُشكّله النموذج المعتمد v3-hard (DER≈2%).
  - الكلمات المشكوكة (ثقة<0.90) تُعرَض في خانة «للمراجعة».

النموذج المعتمد: outputs_v3_hard\best_model.pt
الفهرس القرآنيّ: data\raw\quran\quran-simple.txt
