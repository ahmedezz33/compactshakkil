# CompactShakkil API — دليل التشغيل والبيع

خادمٌ تجاريٌّ يُغلّف محرّكات المشروع ويبيعها كخدمة. العميل يستدعي خادمك عبر HTTP
ولا يرى الكود ولا الأوزان إطلاقًا.

## التشغيل
```
run_api.bat
```
ثم افتح الوثائق التفاعليّة: `http://localhost:8000/docs`
(يحمّل المحرّكات كسولًا: التشكيل/OCR عند أوّل طلب. شغّل بعامل واحد `--workers 1` لأنّ الذاكرة محدودة.)

## إصدار مفتاح لعميل
```
python api_make_key.py "اسم العميل" 100000      REM حدّ 100000 وحدة
python api_make_key.py "عميل مفتوح"              REM بلا حدّ
```
يُضاف المفتاح إلى `api_keys.json` (سرّيّ — غير مرفوع على GitHub). أعطِ العميلَ المفتاحَ فقط.

## نقاط الخدمة
| الطريق | الغرض | الوحدات (للفوترة) |
|---|---|---|
| `POST /v1/diacritize` | تشكيل النصّ | عدد الحروف |
| `POST /v1/pronounce` | النطق (IPA + لاتيني) — أسماء المنتجات/الإعلانات | عدد الحروف |
| `POST /v1/ocr` | استخراج نصّ من صورة | 1 لكلّ صورة |
| `GET /v1/usage` | استهلاك المفتاح | — |
| `GET /health` | فحص | — |

### أمثلة
```bash
# تشكيل
curl -X POST http://localhost:8000/v1/diacritize \
  -H "X-API-Key: cs_xxx" -H "Content-Type: application/json" \
  -d '{"text":"حذرت منظمة الصحة العالمية"}'

# نطق اسم منتج
curl -X POST http://localhost:8000/v1/pronounce \
  -H "X-API-Key: cs_xxx" -H "Content-Type: application/json" \
  -d '{"text":"قَهْوَةُ الصَّبَاحِ"}'
# → {"latin":"qahwahu ṣṣabāḥ","ipa":"qahwahu sˤsˤabaːħ", ...}

# OCR لصورة
curl -X POST http://localhost:8000/v1/ocr \
  -H "X-API-Key: cs_xxx" -F "file=@page.png"

# استهلاك المفتاح
curl http://localhost:8000/v1/usage -H "X-API-Key: cs_xxx"
```

## الفوترة
- كلّ طلب يُسجَّل في `api_usage.log` (سطر JSON: الوقت، المفتاح، الخدمة، الوحدات).
- تسعيرٌ مقترَح: التشكيل/النطق بالألف حرف، والـOCR بالصفحة (1000 وحدة/صفحة، عبر OCR_UNITS_PER_PAGE). مثال: 1 ريال/١٠٠٠ حرف، 0.5 ريال/صفحة — عدّله لسوقك.
- للفوترة الشهريّة: اجمع الوحدات من `api_usage.log` لكلّ مفتاح، أو صفّر `used_units` في `api_keys.json` بداية كلّ دورة.

## النشر للبيع (إنتاج)
1. **دومين + HTTPS**: ضع الخادم خلف Nginx/Caddy مع شهادة TLS (لا تكشف HTTP عاريًا).
2. **إبقاؤه يعمل**: NSSM أو Task Scheduler (ويندوز) ليعمل كخدمة ويعيد التشغيل تلقائيًّا.
3. **عامل واحد** (`--workers 1`) لأنّ بطاقة 8GB تحمل نسخةً واحدةً من النماذج.
4. **لا ترفع** `api_keys.json` ولا `api_usage.log` (مستبعَدان في `.gitignore`).
5. سرعة: التشكيل/النطق سريعان؛ الـOCR أبطأ (نموذج رؤية) — ضع مهلةً مناسبةً للعميل.

> الأوزان تبقى على خادمك فقط. العميل لا يحصل إلا على ردّ HTTP.
